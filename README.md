## Mishel Saadon – Personal Growth & NLP Website

A responsive personal website built with **HTML, CSS, and JavaScript** for Mishel Saadon – an emotional guidance coach and NLP practitioner.
The site combines design, content, and interactive tools to provide value for visitors who seek personal growth, motivation, and practical insights.

## 🌟 Features
- **Responsive Design** – optimized for desktop and mobile.
- **Numerology Calculator** – calculates destiny numbers based on birthdate and name.
- **Daily Message** – motivational NLP-based messages that change daily.
- **Podcasts & Workshops** – embedded media section with video/audio content.
- **FAQ Section** – interactive accordion for common questions.
- **Light/Dark Mode** – toggle between day and night themes.
- **SEO Ready** – optimized metadata, sitemap, and structured content.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (vanilla)
- **Design:** Responsive layout, modern typography, custom animations
- **Tools:** Git, VS Code, Google Search Console
